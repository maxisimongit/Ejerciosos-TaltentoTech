## 📖 Sobre este repositorio

Este repositorio reúne los **ejercicios prácticos resueltos** del curso **"Introducción a la Programación en Python"** dictado en el marco del programa **Talento Tech** del **Gobierno de la Ciudad de Buenos Aires**.

Cada clase cuenta con su propio archivo `.py` **ejecutable**, donde se encuentra el **código completo y el ejercicio práctico solicitado y resuelto** correspondiente a esa sesión.

> 💡 **Objetivo:** documentar el aprendizaje progresivo desde los fundamentos de Python hasta la implementación de operaciones CRUD con bases de datos SQLite.
